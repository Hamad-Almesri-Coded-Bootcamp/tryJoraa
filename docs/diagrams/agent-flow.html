How the agents work

Read it as three bands. The model layer routes — it picks a specialist and phrases an outcome, and holds no tool of its own. The deterministic layer decides — every number that has to be right is computed in a Code node or in SQL. The human gate commits — nothing clinical moves until a person accepts it. A refusal is the one thing that travels without consent.
